## Video Description

This demo video showcases the AudioTranscriber iOS application, demonstrating its key features and functionality for audio recording and transcription.

### Features Demonstrated

- **Real-time Audio Recording**: 30-second segmented recording with live transcription
- **Transcription Services**: OpenAI Whisper API with local fallback
- **Session Management**: SwiftData-based session organization
- **Recording Playback**: Audio player with waveform visualization
- **Transcription Storage**: Persistent transcription storage and retrieval
- **User Interface**: Modern SwiftUI interface with accessibility features

### Technical Highlights

- **SwiftData Integration**: Persistent data storage for sessions and transcriptions
- **Audio Processing**: High-quality audio recording with configurable settings
- **Transcription Pipeline**: Multi-service transcription with fallback mechanisms
- **Performance Optimization**: Efficient audio handling and transcription caching
